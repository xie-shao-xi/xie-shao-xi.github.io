一、初试uniapp

  1. 创建uniapp+vue3项目

    npx degit dcloudio/uni-preset-vue#vite my-vue3-project

  2. 运行项目

    npm run dev:mp-weixin //并通过微信开发工具打开dev/mp-weixin目录

  3. 打包项目

    npm run build:mp-weixin

  4. 引用全局样式

    创建项目后，根目录下自动生成uni.sass文件，里面的样式可以在页面中直接使用，不需要再单独引入

遇到的问题

  1. $callHook is not function

    老版本打包为微信小程序，并在切后台、切回来时会报错，直接更新为最新版本即可
npx @dcloudio/uvm@latest
由原先的3.0.30xxxx更新为3.0.407xxx，该bug就解决了

  2. 打包为小程序分包

    老版本中，打包命令改为npm run build:mp-weixin --subpackage=分包名时
打包后会将代码从build/mp-weixin打包为build/mp-weixin/分包名，但是静态文件的路径仍旧是根目录的路径
需要升级最新版本，再重新打包，静态文件路径才会是/分包名/xx

  3. 自定义组件编译后不显示

    自定义组件需要放在src/components中（怎么自定义目录暂不了解，待了解）

    命名为src/components/custom-com/custom-com.vue

    然后重新编译，编译完看一下编译后小程序文件中的组件目录下存不存在该组件（若不存在，则重新编译）

    若还不显示，则再看看编译后的引用页面中json是否正确引用了该组件

    若编译后代码一切正常，但是还是不显示

    关闭微信开发者工具，重新打开（有时候关闭窗口，重新打开项目就可以）

    查看是否显示的过程中，记得看开发者工具的调试页面（console），看看是不是组件内部代码异常

  4. uniapp自定义组件用于form表单中

    1. 通过definedProps接收value，用于显示

    2. 自定义嵌套一层用于form表单校验时，v-model无效果，改为:value

    3. 使用emit定义change方法

    4. 自定义组件中，触发改变后回调中，执行emit(‘change’, newValue)

    5. 在引入组件的地方

      @change="(value)=>{formData.key=value;formItemRef.onFieldChange(value)}"

    6. watch监听props变化时，若无反应，则改为

      watch(() => props.data, () => {}, { deep: true })
